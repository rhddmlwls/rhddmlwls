# 프로젝트 이름

연구 대상과 확인하려는 질문을 한두 문장으로 작성함.

| 항목 | 내용 |
| --- | --- |
| 상태 | 예정 / 진행 중 / 검증 중 / 완료 / 보류 |
| 최근 실험일 | YYYY-MM-DD 또는 실험 전 |
| 데이터 | 대상, 출처, 기간과 주기 |
| 방법 | 모델, 비교 전략과 평가 방법 |
| 코드와 결과 | 공개한 자료 링크 |

## 연구 질문

- 확인하려는 내용
- 비교할 기준선

## 현재 상태

| 작업 | 상태 | 근거 | 남은 작업 |
| --- | --- | --- | --- |
| 작업명 | 예정 | 실험 전 | 첫 실행 단계 |

## 방법

데이터 기간, 정보 이용 가능 시점, 학습과 평가 구분, 파라미터와 seed, 거래비용, 체결과 수량 가정을 작성함.

## 결과

실험 전이면 결과 없음으로 남김.
완료 후에는 평가기간, 지표 정의, 기준선과 seed를 포함한 표와 근거 파일 링크를 추가함.

## 확인한 내용과 한계

- 관찰한 사실과 근거
- 실패, 미수렴, 결측, 최근 성과 약화 등 한계
- 아직 판단할 수 없는 내용
