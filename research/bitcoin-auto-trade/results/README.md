# 대표 결과와 그림

[프로젝트 개요](../README.md) / [실험 요약](../EXPERIMENTS.md) / [요약 성과 CSV](summary.csv)

본문의 대표 성과, 기준선과 평가 조건을 [summary.csv](summary.csv)에 모음. 모든 매매 경로와 전체 원장을 나열하지 않고 대표 그림 2개와 요약 수치만 제공함.

CSV의 `total_return`과 `max_drawdown`은 소수비율임. 본문에서는 수익률을 백분율로, 최대낙폭을 감소폭의 절댓값으로 표시함. Sharpe는 현금일을 포함한 일별 순자산 수익률의 무위험수익률 0 기준임.

## BTC 국면별 전략

![BTC 국면별 사후 조합과 기준선의 자산 및 낙폭](images/btc_strategy_comparison.png)

2021-05-09~2026-09-30 UTC, seed 42의 단일 포트폴리오 비교임. 각 국면의 최고수익 후보를 연결한 사후 조합은 +589.92%, Sharpe 1.157, 최대낙폭 30.14%였음. 같은 무기한선물의 롱 보유는 +2.67%였음.

그림은 2021년부터의 비교이며 실제 펀딩, 체결당 수수료와 슬리피지 각각 0.05%를 반영함. 상단 자산은 초기자본 대비 배수의 로그축, 하단은 종가 고점 대비 낙폭임.

2024년까지의 자료로 선정한 별도 조합을 2025년 새 자본으로 시작한 결과는 −20.70%임. 이 결과는 선정 방식과 평가기간이 다르며 위 그림에 포함하지 않음.

## 다른 코인 적용

![BTC 고정 규칙을 다른 코인에 적용한 자산 및 낙폭](images/cross_asset_equity_drawdown.png)

공통 평가는 2022-03-01~2026-09-30의 1,675일임. BTC에서 정한 설정과 매매 규칙을 고정하고 각 자산의 과거 자료로 HMM을 다시 학습함.

청록 실선과 점선은 고정 전략의 seed 42와 137, 황색은 해당 선물 롱 보유, 회색은 HMM 없는 양방향 MACD임. 왼쪽은 자산의 로그축, 오른쪽은 종가 고점 대비 낙폭임. 모든 선은 실제 펀딩과 체결 비용을 반영함.

XRP의 MACD는 두 seed 모두 자산 고갈 가능성으로 거부돼 곡선을 만들지 않음. 보유 기준선도 펀딩과 비용을 반영한 무기한선물 롱이며 현물 가격 상승률이 아님.

## 학습과 실패 기록

| 비교 | 기록 |
| --- | --- |
| BTC 국면별 후보 | 301개 중 300개 완료, 상승 국면의 계속 숏 후보 1개는 자산 고갈 가능성으로 거부 |
| BTC 사후 연결에 사용한 HMM | 선택 학습 66회 중 미수렴 1회 |
| 네 코인 공통 기간 | 40개 매매 경로 중 38개 완료, XRP MACD 기준선 2개 거부 |
| 공통 기간 BTC와 ETH | 두 seed 모두 선택 학습 57회 중 미수렴 0회 |
| 공통 기간 SOL | seed 42 / 137에서 선택 학습 57회 중 미수렴 3회 / 4회 |
| 공통 기간 XRP | seed 42 / 137에서 선택 학습 57회 중 미수렴 1회 / 2회 |

57회와 66회는 최초 적합을 포함한 학습 횟수임. 거부 경로는 파산 이후 자산을 보충하거나 수익곡선을 만들지 않음. 이 기록과 높은 낙폭을 대표 수익률과 함께 읽어야 함.
