# Bitcoin Auto Trade Research

**시장 국면에 따른 전략을 설정함으로 거래 성과를 개선하고자 함.** 은닉 마르코프 모형(HMM)으로 시장을 세 상태로 나누고, 국면별 전략을 비교한 오프라인 프로젝트.

일봉과 펀딩 자료를 수집하고, 과거 자료를 이용해 국면을 추정하는 학습 과정과 백테스트를 구현함.

## BTC 국면별 전략 비교

각 국면에서 전체 기간 순수익이 가장 높았던 후보는 상승 국면에서 롱 유지, 횡보 국면에서 MACD 16/35/9와 200일 단순이동평균(SMA200) 롱, 하락 국면에서 MACD 숏이었음. 이 후보들을 단일 포트폴리오로 연결해 다시 실행함. 모든 연결 조합을 탐색한 결과는 아님.

평가기간은 2021-05-09~2026-09-30 UTC임. 초기 10,000 USDT, 매 체결 수수료와 슬리피지 각각 0.05%(5bps), 실제 펀딩과 마지막 종가 청산 비용을 반영한 결과임.

| 전략 | 누적 순수익 | Sharpe | 최대낙폭 |
| --- | ---: | ---: | ---: |
| 국면별 최고수익 후보를 연결한 사후 조합 | +589.92% | 1.157 | 30.14% |
| 같은 무기한선물의 롱 보유 | +2.67% | 0.348 | 84.59% |

![BTC 국면별 사후 조합과 기준선의 자산 및 낙폭](results/images/btc_strategy_comparison.png)

그림은 2021년부터의 전체 기간 비교임. 보유 기준선은 펀딩을 반영한 무기한선물 롱임.

## 다른 코인에 같은 규칙 적용

BTC에서 정한 입력, HMM 설정과 매매 규칙을 고정하고 각 코인의 과거 자료로 다시 학습함. BTC와 동일한 기간인 2022-03-01~2026-09-30을 비교함.

| 자산 | 누적 순수익 | Sharpe | 최대낙폭 |
| --- | ---: | ---: | ---: |
| ETH | +145.72% | 0.654 | 68.65% |
| SOL | +711.75% | 1.056 | 56.87% |
| XRP | +262.14% | 0.722 | 45.19% |

최대 낙폭이 BTC보다 더 커서 Sharpe가 더 작게 나옴.

[네 코인의 자산곡선과 요약 성과](results/README.md#다른-코인-적용)를 함께 제공함.

## 평가 가정과 한계

- 학습과 정규화는 이전 관측만 사용함(look-ahead bias를 방지하기 위함). 상승장, 횡보장, 하락장은 은닉 마르코프 모델이 분류한 국면들을 수익률 순서로 붙인 상대적 이름임.
- 종가 신호는 다음 시가에 체결함. 진입 비용 차감 후 자산의 1배로 수량을 정해 청산까지 고정하고, 반전은 양쪽 체결 비용을 반영함.
- 펀딩의 실제 부호와 시각을 적용함. 유지증거금과 강제청산은 모델링하지 않음.
- Sharpe는 현금일을 포함한 일별 순자산 수익률의 무위험수익률 0 기준임. 최대낙폭은 종가 기준 감소폭의 절댓값임.
- 미수렴과 거부 경로도 기록함. 이미 반복해서 분석한 과거 자료이므로 후반 구간도 미사용 최종 테스트로 해석하지 않음.
