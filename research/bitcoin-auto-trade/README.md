## 연구 질문

- HMM의 상태 구분이 현재 시장 흐름을 얼마나 설명하는지
- 관측창, 관측 변수, 상태 지속시간에 따른 전략 결과 차이
- 거래비용, 펀딩, seed에 따른 성과 차이
- 전체 기간에서 좋은 후보가 최근 구간에서도 유지되는지

## 방법

기본 3변수는 관측창별 로그수익률, 효율비, taker 매수 체결 불균형임. 5변수 후보는 여기에 변동성20과 펀딩평균20을 추가함. HMM 상태는 과거 학습 구간의 수익률 순서로 상승, 횡보, 하락으로 이름을 붙임.

- 학습 365봉, 재학습 30봉, 상태 이름 60봉, 디코딩 61봉. 고정 seed는 42/137
- 학습, scaler, 상태 이름에는 현재 봉 이전의 학습 관측만 사용함
- 현재 종가에서 끝나는 창의 마지막 상태와 확률로 판단함. 전체 시계열의 평활 확률로 과거 신호를 대체하지 않음
- 일반 종가 신호는 다음 시가에 실행함. 초기 10,000 USDT, 진입 비용 차감 후 자산 1배의 BTC 수량을 청산까지 고정함
- 편도 수수료 5 bps와 슬리피지 5 bps, 실제 펀딩 이벤트, 마지막 종가 청산 비용을 반영함
- 반전 시 청산과 재진입 양쪽 비용을 내고 남은 자산으로 새 수량을 정함. 같은 시각의 펀딩은 매매 전 기존 보유분에 적용함

일별 펀딩 집계의 이용 가능 시각은 다음 UTC 일자 00:05로 가정함. 펀딩 이벤트의 mark가 없으면 해당 일자 시가를 대용함. 실시간 연결 시 실제 이벤트 시각, 수신 시각, 이용 가능 시각을 따로 검증할 필요가 있음.

## 결과

두 seed 중 낮은 일반 Sharpe(Rf=0) 순으로 정렬함. 같은 관측 변수, 모델 종류, 매매 규칙의 파라미터 변형을 한 전략군으로 묶고 최고 변형 하나를 대표로 선택함.

| 전략군 | 상승 / 횡보 / 하락 | 최저 seed Sharpe | 평균 Sharpe |
| --- | --- | ---: | ---: |
| 펀딩 5변수 HMM | 롱 / EMA / 현금 | 1.031 | 1.057 |
| 60일 3변수 HMM | EMA / EMA / 현금 | 0.787 | 0.828 |
| 120일 3변수 HMM | 모멘텀90 / EMA / 현금 | 0.776 | 0.837 |

전체 기간을 이미 살펴본 뒤 고른 사후 탐색 순위임. 1위의 2025년 이후 Sharpe는 0.106 / 0.400으로 약했고, 선택 학습은 seed별 1/66회와 4/66회 미수렴함. 최근 구간도 미사용 테스트가 아님. 세 공개 후보 모두 하락 국면에서 현금이며 숏은 사용하지 않음.

## 확인한 점

- 상승과 하락은 상대적인 군집 이름임. 현재 국면의 설명력과 미래 수익, 숏 이익은 별도로 평가해야 함
- 상태를 오래 유지한다고 수익이 좋아지는 것은 아님. 전환 횟수, 유지기간, 비용 차감 손익을 함께 볼 필요가 있음
- 비용과 펀딩에 따라 전략 선택이 달라짐. 비용 0의 진단은 실제 체결 성과와 구분함
- 전체 기간 성과만 보면 최근 약화가 가려짐. 두 seed와 최근 구간을 같이 확인함
