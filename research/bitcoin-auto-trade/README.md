# Bitcoin Auto Trade Research

**시장 상태에 따라 매매 규칙을 바꾸면 거래비용을 반영한 뒤에도 성과가 개선되는지 연구함.** 은닉 마르코프 모형(HMM)으로 시장을 세 상태로 나누고, 국면별 전략을 비교한 오프라인 연구임.

일봉과 펀딩 자료를 수집하고, 과거 자료만으로 국면을 추정하는 학습 과정과 다음 시가 체결 백테스트를 구현함. 과거 고수익 조합과 다른 코인 적용 사례를 확인했으나, 미래 하락 예측의 개선과 전략 선정 이후의 성과 지속성은 확인하지 못함.

## BTC 국면별 전략 비교

5변수 HMM과 10일 후행 확률 평균을 고정하고 국면마다 100개 후보와 공통 현금을 비교함. 301개 중 300개를 완료했고, 1개는 자산 고갈 가능성으로 거부함.

각 국면에서 전체 기간 순수익이 가장 높았던 후보는 상승에서 롱 유지, 중간에서 MACD 16/35/9와 200일 단순이동평균(SMA200) 필터 롱, 하락에서 필터 없는 MACD 숏이었음. 이 후보들을 단일 포트폴리오로 연결해 다시 실행함. 모든 연결 조합을 탐색한 결과는 아님.

평가기간은 2021-05-09~2026-09-30 UTC임. 초기 10,000 USDT, 매 체결 수수료와 슬리피지 각각 0.05%(5bps), 실제 펀딩과 마지막 종가 청산 비용을 반영한 seed 42 결과임.

| 전략 | 누적 순수익 | Sharpe | 최대낙폭 |
| --- | ---: | ---: | ---: |
| 국면별 최고수익 후보를 연결한 사후 조합 | +589.92% | 1.157 | 30.14% |
| 같은 무기한선물의 롱 보유 | +2.67% | 0.348 | 84.59% |

**전체 자료에서 후보를 고른 사후 성과임.** 2024년까지의 자료로 선정한 별도 조합을 2025-01-01~2026-09-30에 새 자본으로 시작한 결과는 **−20.70%, Sharpe −0.698, 최대낙폭 26.74%**였음. 높은 과거 수익을 전략 선정 이후의 성과로 해석하지 않음.

![BTC 국면별 사후 조합과 기준선의 자산 및 낙폭](results/images/btc_strategy_comparison.png)

그림은 2021년부터의 전체 기간 비교이며 2025년 신규 시작 조합은 포함하지 않음. 보유 기준선도 실제 펀딩을 반영한 무기한선물 롱임.

## 다른 코인에 같은 규칙 적용

BTC에서 정한 입력, HMM 설정과 매매 규칙을 고정하고 각 코인의 과거 자료로 다시 학습함. 코인별 최적화 없이 **2022-03-01~2026-09-30의 동일한 1,675일**을 비교함.

네 코인의 입력 시작을 2020-10-01로 맞췄으므로 아래 BTC 대조군은 앞의 BTC 실험과 입력 시작, 재학습 일정 및 평가기간이 다름. 각 셀은 seed 42 / 137 순이며 실제 펀딩과 같은 체결 비용을 반영함.

| 자산 | 누적 순수익 | Sharpe | 최대낙폭 |
| --- | ---: | ---: | ---: |
| BTC 대조군 | +485.34% / +569.86% | 1.275 / 1.325 | 33.43% / 34.05% |
| ETH | +145.72% / +132.38% | 0.654 / 0.637 | 68.65% / 64.57% |
| SOL | +711.75% / +691.15% | 1.056 / 1.053 | 56.87% / 49.23% |
| XRP | +262.14% / +108.13% | 0.722 / 0.535 | 45.19% / 50.59% |

SOL은 두 seed에서 비슷한 성과를 냈으나 ETH의 낙폭과 XRP의 초기값 민감도가 컸음. XRP seed 137의 Sharpe는 선물 롱 보유 0.533과 거의 같았음. 상관된 암호자산 종목의 과거 비교이며 다른 자산군 전체에 대한 일반화 검증은 아님.

[네 코인의 자산곡선과 요약 성과](results/README.md#다른-코인-적용)를 함께 제공함.

## 평가 가정과 한계

- 학습과 정규화는 이전 관측만 사용함. 상승, 중간, 하락은 학습자료의 수익률 순서로 붙인 상대적 이름임.
- seed 42와 137은 각각 10개 초기값으로 학습하고 학습자료를 가장 잘 설명하는 모델을 선택하는 두 묶음임.
- 종가 신호는 다음 시가에 체결함. 진입 비용 차감 후 자산의 1배로 수량을 정해 청산까지 고정하고, 반전은 양쪽 체결 비용을 반영함.
- 펀딩의 실제 부호와 시각을 적용하며 산정 기준 가격이 없으면 해당 일자 시가를 대용함. 유지증거금과 강제청산은 모델링하지 않음.
- Sharpe는 현금일을 포함한 일별 순자산 수익률의 무위험수익률 0 기준임. 최대낙폭은 종가 기준 감소폭의 절댓값임.
- 미수렴과 거부 경로도 기록함. 이미 반복해서 분석한 과거 자료이므로 후반 구간도 미사용 최종 테스트로 해석하지 않음.
