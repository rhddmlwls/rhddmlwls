# 설정 예시

[프로젝트 개요](../README.md) / [검산 데이터](../results/README.md)

공통 조건은 두 설정에 모음. 공개한 [실행기](../CODE.md)에서 사용하며, [가격과 펀딩 CSV](../data/README.md)를 먼저 준비해야 함.

| 설정 | 평가 조건 |
| --- | --- |
| [btc.toml](btc.toml) | BTC 사후 조합과 롱 보유, 2021-05-09~2026-09-30, seed 42 |
| [transfer.toml](transfer.toml) | 공통 기간 비교의 ETH 예시, 2022-03-01~2026-09-30, seed 42 / 137 |

다른 코인의 공통 기간 실험도 같은 모델과 매매 조건을 사용함. 원본 설정 간 차이는 실험 이름, 아래 심볼과 입력 폴더임.

| 자산 | `[data].symbol` | `[paths].data_dir` |
| --- | --- | --- |
| BTC | `BTCUSDT` | `../data/cross_asset/BTCUSDT` |
| ETH | `ETHUSDT` | `../data/cross_asset/ETHUSDT` |
| SOL | `SOLUSDT` | `../data/cross_asset/SOLUSDT` |
| XRP | `XRPUSDT` | `../data/cross_asset/XRPUSDT` |

직전 365개 관측으로 학습하고 30일마다 재학습함. 오늘 종가까지 계산된 상승·횡보·하락 확률을 각각 최근 10일간 평균내고, 평균 확률이 가장 큰 국면을 선택함. 매일 가장 오래된 하루를 빼고 새 하루를 넣음. 미래 자료는 사용하지 않음.

예를 들어 최근 10일 평균이 상승 65%, 횡보 20%, 하락 15%이면 상승으로 판단함. 하루의 확률 급변에 덜 민감해지는 대신 국면 전환에 늦게 반응할 수 있음. `smoothing_windows = [10]`을 변경하면 평균 기간을 바꿀 수 있음.

종가 신호는 다음 시가에 체결하고 진입 후 수량을 고정함. 수수료와 슬리피지는 체결당 각각 0.05%이며 실제 펀딩과 마지막 종가 청산을 반영함. `[paths]`의 상대경로는 설정 파일이 있는 폴더를 기준으로 함.
