# 고급금융수학: 시장 국면의 지속시간 정보와 최적 투자

상태: 제안서 작성, 모형 구현 예정임.

## 연구 질문

현재 국면의 확률이 같아도 국면의 초기인지 후기인지에 관한 정보가 최적 투자 비중과 기대효용을 바꾸는지 분석하려는 연구임.

## 비교 계획

전환율이 일정한 2상태 모형과 각 국면을 초기 단계와 후기 단계로 나눈 4상태 모형을 비교할 계획임. 평균 국면 지속기간을 같게 맞춰 지속시간 구조에 따른 차이를 확인함.

가격으로 숨은 국면을 추정하는 필터링과 최적 투자 문제의 Hamilton–Jacobi–Bellman(HJB) 방정식을 연결함. 단계 정보를 생략했을 때 투자 비중과 기대효용이 얼마나 달라지는지 평가할 계획임.

## 다음 단계

- 선행연구와 비교해 연구 질문과 모형 가정을 구체화함.
- 효용함수, 투자 제약과 수치해법을 정함.
- 수치 예시를 구현하고 실증 분석의 범위를 결정함.
