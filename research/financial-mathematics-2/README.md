# 금융수학2: BTC 옵션의 변동성 모형과 헤지 성능 비교

상태: 주제와 실험 범위 기획 중임.

## 연구 질문

옵션 가격을 잘 맞추는 모형이 같은 거래 조건에서 헤지 오차도 줄이는지 확인하려는 연구임.

## 비교 계획

Black–Scholes와 Heston에 같은 BTC 옵션 자료를 사용해 모형을 보정하고 가격 적합도를 비교할 계획임. 이후 구간에서는 거래 시점, 델타 헤지 주기와 비용을 같게 맞춰 헤지 오차를 비교함.

보정에 사용한 가격을 설명하는 능력과 이후 가격 변화에 대응하는 헤지 성능을 나눠 평가함.

## 다음 단계

- 데이터 기간, 만기와 행사가 범위, 시세 품질 기준을 정함.
- 모형별 보정 방식, 헤지 상품과 재조정 주기, 거래비용 가정을 확정함.
- Local volatility를 확장 비교에 포함할지 결정함.
